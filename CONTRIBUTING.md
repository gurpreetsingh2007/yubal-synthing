# Contributing

This is a small, independently maintained hobby fork. Bug reports, corrections, and focused fixes are welcome, but there is no promise of review or release timelines.

- Open issues and pull requests in this repository: <https://github.com/gurpreetsingh2007/yubal-synthing>
- For the original Yubal project, use <https://github.com/guillevc/yubal>.
- Keep changes small and include steps to reproduce bug reports.
- Never include cookies, `.env` files, credentials, or personal configuration in issues or commits.
